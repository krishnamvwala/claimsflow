# ClaimsFlow

Healthcare claims analytics, denial prevention, and revenue recovery platform built with BigQuery, dbt, Airflow, Python, and Power BI.

## Project status

ClaimsFlow has completed the Phase 0 discovery and success-contract baseline. Requirements, acceptance criteria, machine-readable source-data contracts, the governed metric dictionary, and seven accepted architecture decisions are documented and automatically validated.

The next blueprint milestone is Phase 1 implementation scaffolding: reproducible local tooling, dependency locks, the initial Python/dbt/Airflow project layout, Terraform environment roots, and CI component gates. No real healthcare or customer data is permitted.
