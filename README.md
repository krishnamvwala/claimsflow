# ClaimsFlow

Healthcare claims analytics, denial prevention, and revenue recovery platform built with BigQuery, dbt, Airflow, Python, and Power BI.

## Project status

ClaimsFlow is in Phase 0: Discovery and Success Contract. Requirements, acceptance criteria, machine-readable source-data contracts, and the governed metric dictionary are documented. Implementation will proceed after the initial architecture decisions are approved.
